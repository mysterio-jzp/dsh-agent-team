## 设计选择（已按已拍口径落）

- **清单位置**：讨论页里（已拍 2026-10-14 09:28），⛔ 不开独立顶层页；讨论页页签本批为 `讨论 / 待办` 两枚（`产物` 随 C 那笔加 —— 见下面「本批落地范围」；⛔ 参照里不留点了会给空白的入口）。
- **与 claim 的区分同时落在形状与语义**：待办卡＝圆角卡＋状态签（待认领／已认领／已回复／已结案）＋动作在右侧；
  claim 行＝左侧竖条＋方形 `CLAIM` 标记＋只有 `active/done`。动作面也不一样：人类认领待办，claim 归成员自己 release/done。
- **认领＝仅标记 ＋ 可见**：认领后卡片描边变蓝并显示「已由 @jzp 认领 · 时刻」，⛔ 不排他、不锁别人的动作。
- **幂等要看得见**：重复分发或重复认领都弹一条提示（"这次没有新建／没有变更"），而不是静默成功 —— 发起者必须知道结果不是新建。
- **计数徽标**：为 0 隐藏；`aria-label` 落在控件上（"N 条待办需要我处理"），⛔ 数字不能只存在于视觉徽标里。

## 要谁拍

- 待办项**谁可结案** —— **权利不属于待确认**：`发起者与人类都可` 在**批准版** `8d2ab59` 的 `spec.md:42` 已固化（上一版把这条列在"要谁拍"里，是登记位置问题、不是口径未定）。**待确认的是入口的一处替换**：未结案卡上的第三个动作，从「取消认领」换成「结案」。
  批准版两帧上是「取消认领」：`data-unclaim-todo` 各 **10 处 ＝ 8 枚 `<button>`（其中 **4** 枚带 `hidden`）＋ 2 处脚本选择器**（`:1278`／`:1282`），`data-close-todo` **0** 处；修订笔 `45b662b1` **撤销 8 枚、补 8 枚**，其 `data-close-todo` **9 处 ＝ 8 枚按钮（无一 `hidden`）＋ 1 处脚本选择器**（`:1281`）。
  ⚠ `:1278` 会把隐藏那枚**放出来** ⇒ 同一帧里隐藏态与可见态并存，**"可见按钮"在静态 HTML 上定不下来**，一律按**按钮数**记。
  理由：认领＝**仅标记 ＋ 不排他** ⇒ 本就没有"该被取消"的东西，而"认领了但我不做了"需要出口，`结案` 补的正是它。
- 频道徽标**数什么**（默认数该频道下全部未结案）—— 只影响那一处的数。

## 本批落地范围（2026-10-14 修订笔登记）

**本批落地：认领／在讨论里回复／人类结案；人类自建待办与取消认领不在本批。**

- 三项都在卡片的同一动作组里：`认领`（标记＋可见，不排他）、`在讨论里回复…`（跳到讨论时间线）、**`结案`**（人类自己的收口入口）。
  **「结案」出现在未结案三态卡上（待认领／已认领／已回复都算）**，已结案卡上⛔ 不再有它 —— 账本对 `pending` 也放行人类 `close`，
  若只画在"已回复"上，人类面对一条"我不用做"的待认领项就没有出路。视觉上它是动作组里最后、最轻的一枚（主按钮仍是当前状态该做的那一步）。
- 撤回（`cancelled`）是**发起者**的动作，人类侧没有这个入口；撤回项也不进这张清单（Host 侧已落地）。
- 页签本批只落 `讨论`／`待办` 两枚，`产物` 随 C 那笔加。⇒ **本批图里没有它，参照上与"本批不落地的东西"零差异**（这正是修订笔 2 摘掉那枚页签与空容器的原因）。

## 与 Host 半的对接（2026-10-14 核）

E 的 Host 半已落地（`feat/human-todos` @ `462b89a`，tree `b8e3630`；该笔零 CSS、零 client 改动）。现读其
`AgentTeamHumanTodo`（`packages/agent-team/src/types/entities.ts`）与原型逐帧对得上：

| 原型上画的 | Host 实体字段 | 说明 |
|---|---|---|
| 待办卡标题 | `title` ＋ `normalizedTitle` | 去重按 `(threadRef, normalizedTitle)`，"同一件事"由 Host归一，⛔ 客户端不自己比标题 |
| 频道行徽标那个数 | `channelRef` | 计数是 **Channel 属性**（覆盖该 workspace 全部 active 频道、含 0），只数 `pending`/`claimed`/`answered` ⇒ 与原型"入口＝合计"一致 |
| 四态状态签 | `state`: `pending`／`claimed`／`answered`／`closed`／`cancelled` | 原型画的前三态直接对应；`closed`／`cancelled` 是终态（原型"已结案"帧） |
| 「已由 @jzp 认领 · 时刻」 | `claimedBy` ＋ `claimedSequence` | 认领＝仅这两个字段，**不排他**，与原型"仅标记＋可见"一致 |
| 「在讨论里回复」后跳回条目 | `answeredMessageRef` | 原型时间线上那条「回复待办」标记就挂这个 |
| 结案 | `resolvedBy` ＋ `resolvedSequence` | 发起者与人类都可（已按默认固化） |

⇒ **界面半不需要 Host 再加字段**；按冻结原型画即可。若要加界面侧的新展示（例如"认领人是不是我"），
只用现有字段推导，⛔ 不为展示新增账本字段。
