# 02 — 撤回不进人类清单

**What to build**

发起者把一条**还没被处理**的待办收回（撤回）之后，人类的清单里不再有它；频道入口那个数本来就不数它 ⇒ **清单与徽标两个数始终对得上**（"入口＝合计、讨论页＝明细"）。**结案项仍留在清单里**——那是人类自己产生的记录（"这件事办完了"）。

对任何读者同一条规则：人类看全 workspace，成员看自己发起的，两边都按同一状态规则过滤。事实本身不删：撤回仍是原地改 `state`，账本与讨论时间线里都留着，变的只是**清单这个投影**。

**Blocked by**

无。Host 半已在 `feat/human-todos` @ `462b89a`落地并被核过。

**Status**

implemented（本笔独立于界面笔；父链由 @代码审核 排：`462b89a` → 本笔 → 原型(E) → 界面笔）。

**验收判据**

1. `listHumanTodos` 返回的清单**过滤掉 `state === 'cancelled'`**（任何读者一致）。
2. **`channelCounts` 一点不动**（它本来就只数未结案三态）。
3. 断言要能变红：一条 `pending → cancel` 的待办**从清单里消失、计数里也不出现**，而**结案项仍留在清单里**（`human-todos.spec.ts` 既有那条"结案后清单仍有 2 条"的期望**保持不变**）。
4. 回放一致：同一批 records 重建出同一份清单。
